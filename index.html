Relik Sejarah Analytics adalah aplikasi internal untuk membantu pengelola channel Relik Sejarah membaca kinerja konten melalui YouTube Analytics API.

Aksesnya baca-saja. Situs ini merupakan halaman informasi, bukan tempat login atau tampilan data Analytics channel.

Baca kebijakan privasiHubungi pengelola

Fungsi aplikasi

Data untuk evaluasi konten, bukan akses penuh ke akun.

Aplikasi mengambil laporan kinerja channel yang diotorisasi pemilik. Data dipakai untuk meninjau jumlah penayangan, perkiraan waktu tonton, dan durasi tonton rata-rata sebagai bahan pengembangan channel.

Aplikasi tidak meminta izin untuk mengunggah, mengedit, atau menghapus video. Akses Gmail, Drive, data pembayaran, dan sandi Google bukan bagian dari izin ini.

Cara pemrosesan

Dari laporan ke bahan keputusan.

  1. Pemilik memberi persetujuan melalui halaman otorisasi Google. Aplikasi tidak meminta sandi Google secara langsung.
  2. Alat di VPS mengambil laporan melalui YouTube Analytics API dan menyimpannya secara terpisah dari berkas situs ini.
  3. Hermes Agent membantu membaca laporan. Bagian data yang diperlukan dapat diproses penyedia AI, lalu hasilnya disampaikan kepada pemilik, termasuk melalui percakapan Telegram.

Penjelasan pemrosesan, penyimpanan, dan pencabutan akses tersedia di halaman privasi.

Ketentuan penggunaan

Untuk pengelola Relik Sejarah.

Aplikasi ini ditujukan untuk penggunaan internal oleh pemilik atau pengelola yang diberi izin, bukan layanan analitik terbuka bagi akun orang lain.

Dengan menggunakan aplikasi yang mengakses YouTube API Services ini, pengguna juga menyetujui Ketentuan Layanan YouTube. Pemrosesan data aplikasi dijelaskan dalam kebijakan privasi.

Relik Sejarah Analytics bukan produk Google atau YouTube dan tidak mengklaim telah diverifikasi atau disetujui oleh keduanya.
